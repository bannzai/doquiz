# documents/design

bannzai に見せて方向を決めてもらうための資料の置き場。資料ごとに `<用途>-<日付>/` のディレクトリを作り、単独でブラウザで開ける `index.html` を置く。

- `data-structure-2026-11-17/`: 端末内に保存する型の定義と、利用者の操作ごとに読み書きするデータの表 (構想の確認の資料)
- `mock-2026-11-18/`: 主要画面のモック 6 画面 (本を選ぶ・本と出題の設定・読書中・クイズと判定・履歴・購入)。見た目と体験の方向の確認の資料。`canvas.json` と `*.dc.html` は Claude Design の canvas に公開したファイルで、単独では表示できない。`index.html` は同じ 6 画面を単独で開ける形に並べたもの
