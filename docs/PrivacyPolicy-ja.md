# プライバシーポリシー

bannzai（以下「提供者」といいます。）は、提供者の提供する iOS アプリ「doquiz」（以下「本サービス」といいます。）における、ユーザーについての個人情報を含む利用者情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

## 収集する利用者情報および収集方法
本ポリシーにおいて、「利用者情報」とは、ユーザーの識別に係る情報、通信サービス上の行動履歴、その他ユーザーまたはユーザーの端末に関連して生成または蓄積された情報であって、本ポリシーに基づき提供者が収集するものを意味するものとします。

### 端末内にのみ保存する情報（提供者は収集しません）
本サービスが扱う次の情報は、**ユーザーの端末内にのみ保存し、提供者のサーバーにも外部のサービスにも送信しません**。本サービスは提供者のサーバーを持たず、提供者はこれらの情報を収集・閲覧できません。

- ユーザーが登録した本の名前と出題の設定（出題する問いの種類、出題への希望の文）
- 読書の記録（読書を始めた日時と終えた日時）
- 読書中に取り込んだ画面から抽出した本文
- 本文から作成した問い、模範の答え、根拠として示す本文の引用
- ユーザーの回答とその判定
- 初回の同意の説明に同意したかどうか
- 無料で始めた読書の回数（有料サービスを購入しておらず、無料体験の期間でもない状態で始めた読書の回数）

これらの取扱いは次のとおりです。

- **画面の画像は保存しません。** 読書中に取り込んだ画面の画像は、端末内で文字認識（Apple の Vision フレームワーク）にかけて本文を抽出するためだけに使い、画像そのものは保存しません。保存するのは抽出した本文だけです。
- **本文を外部の AI サービスに送信しません。** 問いの作成と、穴埋めおよび記述の回答の判定は、端末内で動作するモデル（Apple の Foundation Models フレームワーク）で行います。Apple のサーバーで処理する Private Cloud Compute は使いません。
- **取り込みは画面全体が対象です。** 取り込みは、ユーザーが「読書を始める」を押し、iOS が表示する画面共有の選択画面で画面全体を選んだ時に始まり、「読書を終える」を押すと止まります。その間に画面に表示された文字は、読書アプリ以外のものも本文として抽出され、端末内に保存されることがあります。
- **端末のバックアップに含まれることがあります。** 端末内に保存した情報は、ユーザーが端末の iCloud バックアップ等を有効にしている場合、ユーザー自身のバックアップに含まれることがあります。バックアップは Apple がユーザーに提供する機能であり、その取扱いは Apple のプライバシーポリシー（ <https://www.apple.com/jp/legal/privacy/> ）によります。本サービスは、これらの情報を iCloud（CloudKit）で同期しません。
- 提供者は、これらの情報のバックアップを行いません。端末の変更・初期化・アプリの削除により情報が失われた場合、提供者は復旧できません。

### 外部のサービスに送信される情報
本サービスが利用する外部のサービスは、有料サービスの購入を扱う次の 2 つだけです。広告の配信、利用状況の計測（アナリティクス）、クラッシュの収集のための外部のサービスは利用しません。

#### RevenueCat（購入状況の管理）
本サービスは、有料サービスの購入状況の確認および復元のため、RevenueCat, Inc.（米国）が提供する RevenueCat を利用します。本サービスにはアカウントの登録がなく、提供者は RevenueCat に氏名・メールアドレス等のユーザーを直接特定する情報を渡しません。

RevenueCat が受け取る情報は、RevenueCat の公式の文書（いずれも 2026年11月20日に確認）によると次のとおりです。

- **購入の履歴**: 「RevenueCat collects purchase history from users」（出典: <https://www.revenuecat.com/docs/platform-resources/apple-platform-resources/apple-app-privacy> ）。取引の情報として「Last seen time that the end user used your app or digital product; Apple receipt file」が挙げられています（出典: <https://www.revenuecat.com/privacy> ）。
- **匿名の利用者 ID**: 本サービスは利用者 ID を指定しないため、RevenueCat の SDK が無作為の ID を作成して端末内に保持します。「RevenueCat will generate a new random App User ID (prefixed with $RCAnonymousID:) for you, and will cache it on the device」「In the event that the user deletes and reinstalls the app, the cache will be cleared and a new random anonymous App User ID will be generated」（出典: <https://www.revenuecat.com/docs/customers/identifying-customers> ）。
- **端末の技術的な情報**: 「technical information related to an end user’s mobile device or computer, such as device type, operating system」（出典: <https://www.revenuecat.com/privacy> ）。
- **言語・地域の設定と通貨コード**: 「RevenueCat does not collect precise or coarse location data, only locale and currency code」（出典: <https://www.revenuecat.com/docs/platform-resources/apple-platform-resources/apple-app-privacy> ）。位置情報は収集されません。

RevenueCat は、これらの情報を提供者の委託を受けた処理者として取り扱い（「We are not the Data Controllers of this data and act as Data Processors」）、米国の Amazon Web Services 上に保存します（「stored securely on Amazon Web Services (“AWS”) in the USA」。出典はいずれも <https://www.revenuecat.com/privacy> ）。RevenueCat における情報の取扱いは、RevenueCat, Inc. のプライバシーポリシー（ <https://www.revenuecat.com/privacy> ）によります。

本文・問い・回答などの「端末内にのみ保存する情報」は、RevenueCat に送信しません。広告のための識別子（IDFA）は利用せず、購入の履歴を広告や他社のアプリをまたいだ追跡に利用しません。

#### Apple（決済）
アプリ内購入の決済は Apple Inc. が処理します。提供者は、クレジットカード情報等の決済情報を取得しません。Apple における情報の取扱いは、Apple のプライバシーポリシー（ <https://www.apple.com/jp/legal/privacy/> ）によります。

### 提供者が収集する情報
本サービスはアカウント登録を必要とせず、提供者がユーザーの個人情報をサーバーで収集・保管することはありません。ユーザーがメールで問い合わせを行った場合に限り、そのメールアドレスと問い合わせ内容を取得します。

## 利用目的
利用者情報の具体的な利用目的は以下のとおりです。

- 有料サービスの購入状況の確認・復元、および不正な購入の防止のため
- 購入の件数・売上など、個人を特定しない形での販売状況の把握のため
- 本サービスに関するお問い合わせへの対応のため
- 本サービスに関する規約、ポリシー等に違反する行為への対応のため
- 本サービスに関する規約等の変更などを通知するため

## 第三者提供および外国にある第三者への提供
提供者は、利用者情報のうち、個人情報については、あらかじめユーザーの同意を得ないで、第三者に提供しません。ただし、次に掲げる場合はこの限りではありません。

- 提供者が利用目的の達成に必要な範囲内において個人情報の取扱いの全部または一部を委託する場合
- 合併その他の事由による事業の承継に伴って個人情報が提供される場合
- 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、ユーザーの同意を得ることによって当該事務の遂行に支障を及ぼすおそれがある場合
- その他、個人情報の保護に関する法律（以下「個人情報保護法」といいます。）その他の法令で認められる場合

上記の委託の定めにかかわらず、外国にある第三者への提供は次のとおりです。本サービスは、有料サービスの購入状況の管理のため、「外部のサービスに送信される情報」に記載した購入に関する情報を、米国にある RevenueCat, Inc. に送信し、同社はこれを米国で保存します。送信する情報に、氏名・メールアドレス・本文は含まれません。米国の個人情報の保護に関する制度については、個人情報保護委員会が公表している情報（ <https://www.ppc.go.jp/enforcement/infoprovision/laws/> ）をご覧ください。RevenueCat, Inc. が講じる措置は、同社のプライバシーポリシーおよびデータ処理に関する契約（ <https://www.revenuecat.com/dpa> ）によります。ユーザーは、有料サービスを購入する前に、この送信の内容を確認するものとします。

## 保存期間
- 端末内にのみ保存する情報: ユーザーがアプリ内で読書の記録もしくは本を削除するか、アプリを端末から削除するまで、端末内に保存されます。提供者は保有しません。
  - ただし、無料で始めた読書の回数は、iOS が提供する端末内の保存領域である Keychain に保存します。現在の iOS は、アプリを削除しても Keychain に保存した情報を端末に残すため、この回数はアプリを削除した後も端末に残り、同じ端末でアプリを入れ直すと引き継がれることがあります。この動作は Apple が文書で定めたものではなく（Apple の担当者の説明「Our keychain documentation has never specified what would happen in this case.」。出典: <https://developer.apple.com/forums/thread/36442> 、2026年11月22日に確認）、今後の iOS で変わることがあります。この回数も端末の外には送信せず、提供者は収集しません。
- RevenueCat が受け取る購入に関する情報: 提供者が RevenueCat の利用を終えるまで RevenueCat に保存されます（RevenueCat のデータ処理に関する契約の定め「Personal Data will be retained until termination or expiry of the Agreement」。出典: <https://www.revenuecat.com/dpa> 、2026年11月20日に確認）。
- お問い合わせのメール: お問い合わせへの対応に必要な期間保存し、不要になった時点で削除します。

## 個人情報の開示・訂正・利用停止・消去
提供者は、ユーザーから、個人情報保護法の定めに基づき個人情報の開示・訂正・利用停止・消去を求められたときは、ユーザーご本人からのご請求であることを確認の上で、遅滞なく対応します（当該個人情報が存在しないときにはその旨を通知いたします。）。ただし、個人情報保護法その他の法令により提供者が義務を負わない場合は、この限りではありません。

情報の削除は、次の方法で行えます。

- 端末内にのみ保存する情報: 提供者が保有していないため、ユーザー自身が消去します。アプリ内で読書の記録または本を削除すると、その読書の記録または本に属する本文・問い・回答が消去されます。アプリを端末から削除すると、端末内に保存した情報は、無料で始めた読書の回数を除いて消去されます（無料で始めた読書の回数の扱いは「保存期間」のとおりです）。
- RevenueCat が受け取る購入に関する情報、およびお問い合わせのメール: 下記のお問い合わせ窓口（bannzai.app@gmail.com）へメールでご請求ください。本サービスにはアカウントの登録がないため、購入に関する情報のご請求の際は、対象を特定するための情報（Apple の領収書に記載された注文番号など）をお尋ねします。対象を特定できない場合は、ご請求に対応できないことがあります。

## プライバシーポリシーの変更手続
提供者は、必要に応じて、本ポリシーを変更します。ただし、法令上ユーザーの同意が必要となるような本ポリシーの変更を行う場合、変更後の本ポリシーは、提供者所定の方法で変更に同意したユーザーに対してのみ適用されるものとします。なお、提供者は、本ポリシーを変更する場合には、変更後の本ポリシーの施行時期および内容をアプリ上での表示その他の適切な方法により周知し、またはユーザーに通知します。
